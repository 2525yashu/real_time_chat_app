ChatApp

A real-time chat application built using React, Socket.IO, and Zustand for state management.
It supports instant messaging, authentication, and live updates without page reloads.

🚀 Features

Real-time messaging (1-on-1 or group)
Socket.IO for instant updates
Zustand for state management
User authentication (JWT)
Responsive design

🛠 Tech Stack
Frontend: React and Zustand.
Backend: Node.js, Express.js
Database: MongoDB + Mongoose
Real-time: Socket.IO
